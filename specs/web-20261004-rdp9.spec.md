- **REQ-1** When the home page loads, the app shows a visible world map as an inline SVG inside `#app` without issuing network requests for map geometry or country metadata.
  `[@test] ../tests/world-map.offline.test.ts`

- **REQ-2** The bundled map dataset includes one entry for every sovereign country and separate widely mapped dependency shown on standard political world maps; the UI renders exactly one SVG `path` per dataset entry and none are omitted.
  `[@test] ../tests/world-map.countries.test.ts`

- **REQ-3** Each country `path` carries a `data-country-code` attribute whose value matches the entry’s ISO 3166-1 alpha-2 code in the bundled dataset.
  `[@test] ../tests/world-map.countries.test.ts`

- **REQ-4** Each country `path` has a non-empty `d` attribute so borders are vector geometry rather than placeholders or bounding boxes only.
  `[@test] ../tests/world-map.geometry.test.ts`

- **REQ-5** Before any country is hovered, no country path is in a highlighted state and the map’s country name display is empty or shows a neutral non-country-specific prompt.
  `[@test] ../tests/world-map.initial-state.test.ts`

- **REQ-6** When the pointer hovers a country path, the map’s country name display shows that country’s English short name exactly as defined in the bundled dataset for its `data-country-code`.
  `[@test] ../tests/world-map.hover.test.ts`

- **REQ-7** While a country path is hovered, that path is in a highlighted state and every other country path is not highlighted.
  `[@test] ../tests/world-map.hover.test.ts`

- **REQ-8** When the pointer leaves a country path and is not over another country path, that country’s highlight is cleared and the country name display returns to the initial empty or neutral state described in REQ-5.
  `[@test] ../tests/world-map.hover.test.ts`

- **REQ-9** In a browser session with network idle after load, hovering France, Brazil, and Japan on the map shows the labels `France`, `Brazil`, and `Japan` respectively in the country name display.
  `[@test] ../e2e/world-map.spec.ts`

## Assumptions

- The bundled dataset is the single source of truth for which countries exist, their ISO codes, English short names, and SVG path data; tests import the same module the app uses to assert counts and labels.
- “Do not simplify or drop countries” means no country entry from the bundled dataset is removed or merged away; cartographic vertex reduction that preserves recognizable borders for every entry is allowed so the project’s 60 KB gzip JavaScript bundle budget in AGENTS.md can still be met.
- “High-resolution borders” means detailed vector `path` geometry shipped in the bundle (not raster tiles or external GeoJSON fetch), not a specific minimum vertex count.
- The country name display is a dedicated element in the DOM (for example an element with `data-testid="country-name"`) updated on hover.
- Highlighted state is expressed with a `data-highlighted="true"` attribute or a `highlighted` class on the hovered path only, observable in the DOM for tests.
- Hover behavior follows pointer events; touch-specific behavior is out of scope unless added later.
- The map uses a fixed viewBox fitting all country paths and scales within the main layout without requiring user pan or zoom for REQ-9.
