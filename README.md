# factory-target-web

Target project for the LambdaLoopers software factory PoC. A minimal Vite + TypeScript web app with Playwright E2E.

## Commands

- Install: `npm ci && npx playwright install --with-deps chromium`
- Dev server: `npm run dev`
- Typecheck: `npm run typecheck`
- Build: `npm run build`
- E2E: `npm run test:e2e`
